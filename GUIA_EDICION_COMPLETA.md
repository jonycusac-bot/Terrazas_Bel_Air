## ⚡ **MÉTODO RÁPIDO PARA ENCONTRAR CUALQUIER COSA:**

1. **Abre `index.html`**
2. **Presiona Ctrl+F** (buscar)
3. **Escribe parte del texto** que quieres cambiar
4. **Cambia solo el texto**, mantén las etiquetas HTML
5. **Guarda** (Ctrl+S)
6. **Recarga la página** (F5)

---

## ⚠️ **REGLAS DE ORO:**

✅ **MANTÉN siempre las comillas** `" "`  
✅ **NO borres las etiquetas** `< >`  
✅ **SOLO cambia el texto** entre comillas  
✅ **GUARDA después de cada cambio**  
✅ **RECARGA la página** para ver cambios
