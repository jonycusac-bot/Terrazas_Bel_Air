# 🏠 Portal Terrazas de Bel Air

Portal web informativo para la comunidad de vecinos Terrazas de Bel Air.

## 🌟 Características

- ✅ **Responsive Design** - Optimizado para móviles
- ✅ **PWA** - Se puede instalar como app
- ✅ **Multiidioma** - Español/Inglés
- ✅ **Sistema de sugerencias** - Email directo al administrador
- ✅ **Galería de fotos** - Mejoras de la comunidad
- ✅ **Documentos descargables** - Actas y documentos importantes
- ✅ **Gestión de contactos** - Información útil para vecinos

## 🚀 Tecnologías

- HTML5
- CSS3 (Responsive)
- JavaScript (Vanilla)
- PWA (Progressive Web App)
- Service Worker (Offline)

## 📱 Instalación como App

1. Abre la web en Chrome/Safari
2. Busca el botón "Instalar App" 
3. Confirma la instalación
4. ¡Ya tienes la app en tu móvil!

## 🔧 Personalización

Todos los datos se pueden personalizar editando directamente los archivos HTML:

- **Nombre comunidad:** Buscar "Terrazas de Bel Air" en `index.html`
- **Teléfonos:** Buscar números de teléfono y cambiar
- **Emails:** Cambiar email del administrador en `script.js`
- **Fotos:** Subir a Imgur y cambiar URLs en `index.html`
